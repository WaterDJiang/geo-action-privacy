概述

GEO Action 是一款 Chrome 浏览器扩展，用于把用户主动上传或输入的 Markdown 内容，按用户选择的平台规则适配并创建为可继续编辑的内容平台草稿。本扩展不会自动公开发布内容。

我们处理的数据

  • 用户提供的标题、摘要、标签、Markdown 正文、封面、图片链接和本地图片。
  • 目标平台必要的登录 Cookie、会话状态或 CSRF 状态。
  • 平台登录状态、草稿 ID、编辑链接、任务阶段、错误和时间。
  • 本地保存的当前编辑会话、可恢复内容草稿历史、平台选择、发布清单、界面偏好、任务历史和重复指纹。
  • 需要原生编辑器的草稿流程中，为写入和验证草稿所需的目标编辑器状态。
  • 用户主动创建的一次性定时任务：触发时间、不可变文章与平台选择快照、状态和关联草稿任务 ID。
  • 用户自行配置的对话、做图和通用 JSON Webhook 请求地址、模型、鉴权密钥、JSON 请求体模板、超时及响应字段设置。
  • 用户通过可选本地 CLI 主动提交的 Markdown、图片、目标平台、确认标记、请求 ID，以及对应的准备记录与任务状态。

我们不持续监控浏览历史，不扫描无关网页，不采集广告标识或行为分析数据，不把平台 Cookie、正文或图片发送给扩展开发者。

使用、存储与共享

数据仅用于解析和适配 Markdown、检查登录、转存用户选择的图片、直接、定时或经本地 CLI 明确确认后创建和验证草稿、恢复本地状态、避免重复草稿，以及执行用户主动发起的 AI 或工作流请求。

本地状态、定时快照、API 密钥和 Webhook 地址保存在 chrome.storage.local，直至用户删除对应任务/连接、清除扩展数据或卸载扩展。完整备份包含密钥时使用用户口令经 PBKDF2-SHA-256 派生密钥并用 AES-256-GCM 加密；无密钥配置模板排除鉴权秘密。

用户直接创建草稿，或用户预先设置的一次性定时任务到点时，必要内容只会直接发送到所选平台；远程图片会从 Markdown 明确引用的来源读取并转存。开发者不运营内容中转服务器，不接收用户草稿或平台 Cookie。

只有用户点击 AI 生成或调用工作流时，用户选择的发送范围（仅标题、标题与摘要或完整文章）和提示词才会发送到其明确选择的第三方 AI API 或通用 JSON Webhook。第三方服务按其自身隐私政策处理数据；密钥和内容不会发送给扩展开发者。

可选本地 CLI 通过用户安装的 Native Host 与扩展通信。Native Host 只允许安装时指定的 GEO Action 扩展 ID，只接受检查、准备、确认创建、查询和取消命令；它不读取平台 Cookie、扩展 API 密钥或任意扩展存储，也不能公开发布、访问任意网址或执行任意脚本。

我们不出售、出租或将数据用于广告、数据经纪、信用评估、贷款或与草稿创建无关的用途。

权限说明

  • storage、unlimitedStorage：保存本地工作区、API/Webhook 配置与密钥、设置、历史以及较长 Markdown 和图片数据。
  • cookies：检查目标平台登录状态并读取草稿流程必要的会话或 CSRF Cookie。
  • declarativeNetRequest、declarativeNetRequestWithHostAccess：临时设置平台接口所需请求头，任务后清理。
  • sidePanel：展示编辑与草稿工作流。
  • tabs：打开登录页、原生编辑器、草稿和支持页面。
  • scripting：仅在用户选择且需要原生编辑器的目标平台标签页中执行扩展包内脚本，写入、保存并验证草稿。
  • alarms：为用户主动创建的一次性定时任务设置触发，不用于周期抓取、广告或分析。
  • nativeMessaging（可选）：只有用户从“CLI 与本地 AI”帮助页点击启用时才申请，用于连接用户主动安装、且只允许当前 GEO Action 扩展 ID 的本机 CLI / Native Host；拒绝或未申请不影响普通功能，仅处理检查、准备、确认创建、查询/取消 CLI 任务，以及在用户再次明确确认后打开该任务结果中已有的草稿链接；不接受任意 URL。
  • http://*/*、https://*/*：访问平台注册端点、用户 Markdown 明确引用的远程图片，以及用户主动配置并选择调用的 AI API 或通用 JSON Webhook。

安全措施

所有可执行代码均包含在扩展包中，不加载远程代码；第三方响应只按文本、JSON 或图片处理，不作为代码执行。平台请求使用 HTTPS。身份验证 Cookie 不写入任务历史或开发者日志。遇到验证码、风控、安全验证或不兼容的平台状态时，扩展停止对应平台。

Chrome Web Store Limited Use

GEO Action 对从 Chrome 权限和目标平台获得的信息的使用，将遵守 Chrome Web Store User Data Policy（包括 Limited Use 要求）。数据仅用于本扩展明确披露的单一用途；除完成用户主动选择的草稿创建所必需外，不向第三方转移，不用于广告、数据经纪、信用评估，也不允许人工读取用户内容。

用户控制与保留

用户可以编辑或删除 API/Webhook 连接、取消定时任务、编辑或清除本地状态、卸载扩展删除全部本地数据、不选择任何特定平台，并在各平台草稿箱查看、编辑或删除已创建草稿。

儿童隐私与政策更新

本扩展不面向 13 岁以下儿童，也不会故意收集 13 岁以下儿童的个人信息。如果数据处理方式发生变化，我们会在生效前更新本政策、商店披露和扩展内必要提示。
