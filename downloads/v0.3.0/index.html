GEO Action 0.3.0 CLI

本页提供 Native Host、CLI 和 AI Skill 的公开安装包。CLI 只创建平台草稿，不执行公开发布。

安装

先在 GEO Action 中打开“设置 → CLI 与本地 AI”，点击“启用 CLI 连接（可选）”，再复制当前扩展 ID。

macOS / Linux：

curl -fsSL https://waterdjiang.github.io/geo-action-privacy/downloads/v0.3.0/install.sh \
  | bash -s -- --extension-id <当前扩展ID>

Windows PowerShell：

& ([scriptblock]::Create((irm https://waterdjiang.github.io/geo-action-privacy/downloads/v0.3.0/install.ps1))) `
  -ExtensionId <当前扩展ID>

手工下载

  • geo-action-cli.tar.gz（macOS / Linux）
  • geo-action-cli.zip（Windows 或通用解压）
  • checksums.txt（SHA-256）
  • install.sh / install.ps1

安装后怎么唤醒

无需手动启动 daemon。保持 Chrome 与 GEO Action 运行，在插件“CLI 与本地 AI”页点击“重新连接 CLI”，然后重新打开 AI 工具会话。

  • Codex：$geo-action 请把 /绝对路径/article.md 准备为微信公众号和知乎草稿
  • Claude Code：/geo-action 请把 /绝对路径/article.md 准备为微信公众号和知乎草稿
  • 其他工具：明确要求“使用 GEO Action”，或直接运行 geo-action doctor。

快速开始

geo-action doctor
geo-action draft prepare article.md --platform wechat,zhihu \
  --asset body-1.png --asset body-2.png --cover cover.png
geo-action draft create <prepared-id> --confirm
geo-action task watch <task-id>
geo-action task open <task-id> --confirm

Markdown 相对正文图片会按文章目录自动读取；额外正文图片可重复使用 --asset，统一封面使用 --cover。

任务结束会返回逐平台结果和草稿链接。先展示列表，只有用户决定后才运行 task open --confirm 一次打开全部可用草稿；任务完成不会自动弹出标签页。

准备阶段不会创建草稿。只有展示检查结果并取得用户确认后，才运行 draft create --confirm。
