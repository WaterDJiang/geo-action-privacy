GEO Action 0.3.0 CLI

本页提供 Native Host、CLI 和 AI Skill 的公开安装包。CLI 只创建平台草稿，不执行公开发布。

安装

先在 GEO Action 中打开“设置 → CLI 与本地 AI”，复制当前扩展 ID。

macOS / Linux：

curl -fsSL https://waterdjiang.github.io/geo-action-privacy/downloads/v0.3.0/install.sh \
  | bash -s -- --extension-id <当前扩展ID>

Windows PowerShell：

& ([scriptblock]::Create((irm https://waterdjiang.github.io/geo-action-privacy/downloads/v0.3.0/install.ps1))) `
  -ExtensionId <当前扩展ID>

手工下载

  • geo-action-cli.tar.gz（macOS / Linux）
  • geo-action-cli.zip（Windows 或通用解压）
  • checksums.txt（SHA-256）
  • install.sh / install.ps1

快速开始

geo-action doctor
geo-action draft prepare article.md --platform wechat,zhihu
geo-action draft create <prepared-id> --confirm
geo-action task watch <task-id>

准备阶段不会创建草稿。只有展示检查结果并取得用户确认后，才运行 draft create --confirm。
