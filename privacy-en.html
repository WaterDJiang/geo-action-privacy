GEO Action Privacy Policy

Last updated: July 24, 2026

Overview

GEO Action is a Chrome extension that adapts Markdown content actively uploaded or entered by the user and creates editable drafts on content platforms selected by the user. It does not automatically publish content.

Data handled

  • User-provided titles, summaries, tags, Markdown text, covers and images.
  • Necessary authentication cookies, session state or CSRF state for selected platforms.
  • Platform login status, draft identifiers, edit URLs, task status, errors and timestamps.
  • The current editing session, recoverable content-draft history, platform selections, publish lists, interface preferences, task history and duplicate fingerprints.
  • User-created one-time schedules, including trigger time, immutable article and destination snapshot, status and related draft-task identifier.
  • The minimum native-editor state required to create and verify drafts.
  • User-configured chat, image and generic JSON Webhook endpoints, models, authentication secrets, JSON request templates, timeouts and response mappings.
  • Markdown, images, selected destinations, confirmation flags, request identifiers, prepared records and task state explicitly submitted through the optional local CLI.

GEO Action does not continuously monitor browsing history, scan unrelated pages, collect advertising identifiers, or perform behavioral analytics.

Use, storage and sharing

Data is used only to adapt content, check login state, transfer user-selected images, create and verify drafts directly, from a user-created one-time schedule, or after explicit confirmation through the local CLI, restore local state, prevent duplicates, and execute AI or workflow actions explicitly started by the user. Local state, scheduled snapshots, API keys and Webhook URLs remain in chrome.storage.local until deleted, cleared or the extension is uninstalled. Authentication cookies remain managed by Chrome and the selected platform.

A complete backup containing credentials is encrypted with a user passphrase using PBKDF2-SHA-256 and AES-256-GCM. The separate configuration template excludes authentication secrets.

When the user starts draft creation, or a one-time schedule previously created by the user becomes due, necessary content is sent directly to the selected platform. The developer does not operate a content relay server and does not receive user drafts or platform cookies. GEO Action does not sell, rent or use data for advertising, data brokerage, creditworthiness, lending or unrelated purposes.

Only when the user starts AI generation or a workflow are the scope selected by the user (title only, title and summary, or the complete article) and the prompt sent to the third-party AI API or generic JSON Webhook explicitly selected by the user. Those services process data under their own privacy policies. Keys and content are not sent to the extension developer.

The optional local CLI communicates with the extension through a user-installed Native Host. The Native Host allows only the GEO Action extension ID selected during installation and accepts only check, prepare, confirm-create, query and cancel commands. It cannot read platform cookies, extension API keys or arbitrary extension storage, publish content publicly, access arbitrary URLs or execute arbitrary scripts.

Permissions

  • storage and unlimitedStorage: local workspace, scheduled snapshots, API/Webhook configuration and large content.
  • cookies: selected-platform login and required session state.
  • DNR permissions: temporary platform-required request headers.
  • sidePanel: the editing workflow.
  • tabs: login pages, native editors and drafts.
  • scripting: packaged code only in a user-selected destination's native editor when required to write, save and verify a draft.
  • alarms: user-created one-time draft triggers only; no periodic scraping, advertising or analytics.
  • nativeMessaging: communication with the optional user-installed local CLI/Native Host, restricted to the configured GEO Action extension ID and the disclosed command set.
  • HTTP/HTTPS host access: registered platform endpoints, remote images explicitly referenced by user Markdown, and AI APIs or generic JSON Webhooks configured and selected by the user.

Security and Limited Use

All executable code is packaged with the extension. Third-party responses are handled only as text, JSON or images and are never executed as code. GEO Action does not load remote code and stops on CAPTCHA, risk-control or security-verification pages.

GEO Action's use of information received from Chrome permissions and target platforms will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only for the extension's disclosed single purpose.

User controls

Users can edit or delete API/Webhook connections, cancel scheduled tasks, edit or clear local state, remove the extension to delete all local data, exclude any platform and view, edit or delete drafts on each platform.
