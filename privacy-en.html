Geo Action Privacy Policy

Last updated: July 17, 2026

Overview

Geo Action is a Chrome extension that adapts Markdown content actively uploaded or entered by the user and creates editable drafts on content platforms selected by the user. It does not automatically publish content.

Data handled

  • User-provided titles, summaries, tags, Markdown text, covers and images.
  • Necessary authentication cookies, session state or CSRF state for selected platforms.
  • Platform login status, draft identifiers, edit URLs, task status, errors and timestamps.
  • The current editing session, recoverable content-draft history, platform selections, publish lists, interface preferences, task history and duplicate fingerprints.
  • The minimum native-editor state required to create and verify Twitter/X and Xiaohongshu drafts.

Geo Action does not continuously monitor browsing history, scan unrelated pages, collect advertising identifiers, or perform behavioral analytics.

Use, storage and sharing

Data is used only to adapt content, check login state, transfer user-selected images, create and verify drafts, restore local state and prevent duplicates. Local state remains in chrome.storage.local until cleared or the extension is uninstalled. Authentication cookies remain managed by Chrome and the selected platform.

When the user starts draft creation, necessary content is sent directly to the selected platform. The developer does not operate a content relay server and does not receive user drafts or platform cookies. Geo Action does not sell, rent or use data for advertising, data brokerage, creditworthiness, lending or unrelated purposes.

Permissions

  • storage and unlimitedStorage: local workspace and large content.
  • cookies: selected-platform login and required session state.
  • DNR permissions: temporary platform-required request headers.
  • sidePanel: the editing workflow.
  • tabs: login pages, native editors and drafts.
  • scripting: packaged code in selected Twitter/X or Xiaohongshu editor tabs only.
  • HTTP/HTTPS host access: registered platform endpoints and remote images explicitly referenced by user Markdown.

Security and Limited Use

All executable code is packaged with the extension. Geo Action does not load remote code and stops on CAPTCHA, risk-control or security-verification pages.

Geo Action's use of information received from Chrome permissions and target platforms will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only for the extension's disclosed single purpose.

User controls

Users can edit or clear local state, remove the extension to delete all local data, exclude any platform and view, edit or delete drafts on each platform.
